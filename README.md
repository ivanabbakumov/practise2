## Введение
В рамках практической работы были получены навыки дизайна с помощью функции SubD в программе Rhino. После подготовки 3D-моделей задачи были реализованы с помощью различных методов производства: фотополимерная 3D-печать, 3D-печать пластиком (для создания ручек и молда под силикон), лазерная резка и заливка эпоксидной смолы в силиконовые формы. Перед работой была проведена подготовительная работа по поиску решений в интернете.
## Задачи
В качестве задач необходимо было выполнить дизайн кольца под фотополимерную печать, сделать 2D-макет броши в виде пасхального яйца, создать специальную подставку под палочки для еды из эпксидной смолы и разработать две ручки для тумбочки в мастерской. Для решения поставенных задач применялись методы реинжиниринга и навыки работы в Rhino и с 3D-принтерами.
