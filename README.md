## Введение
В рамках практической работы были получены навыки дизайна с помощью функции SubD в программе Rhino. После подготовки 3D-моделей задачи были реализованы с помощью различных методов производства: фотополимерная 3D-печать, 3D-печать пластиком (для создания ручек и молда под силикон), лазерная резка и заливка эпоксидной смолы в силиконовые формы. Перед работой была проведена подготовительная работа по поиску решений в интернете.
## Задачи
В качестве задач необходимо было выполнить дизайн кольца под фотополимерную печать, сделать 2D-макет броши в виде пасхального яйца, создать специальную подставку под палочки для еды из эпксидной смолы и разработать две ручки для тумбочки в мастерской. Для решения поставенных задач применялись методы реинжиниринга и навыки работы в Rhino и с 3D-принтерами.

### Подставка под палочки
Чаще всего в качестве идеи для формы выбирают животное, например, панду или кошку. В свою очередь я решил взять за оснвову кита. Работу начинаем с создания самой модели. Далее с помощью спецаильных команд разрезаем модель на две половинки и каждую полувинку закрываем в коробочку [Boundary Box]. Таким образом получаем готовые под печать молды для сликоновых форм.

## Заключение
В ходе практической работы был освоен полный цикл создания изделий: от цифрового дизайна в Rhino с использованием SubD-моделирования до реализации методами лазерной резки, фотополимерной и FDM-печати, а также литья в силиконовые формы. Спроектированы и изготовлены кольцо с космической тематикой, многослойная брошь «Пасхальное яйцо», декоративная подставка для палочек из эпоксидной смолы в виде кита и две функциональные ручки для тумбочки.
